# 交付前自检清单

生成预习物料后逐项检查：

## 教材准确性
- [ ] 版本正确
- [ ] 年级正确
- [ ] 学期正确
- [ ] 科目正确
- [ ] 课次正确
- [ ] 课题正确
- [ ] 生字/单词/数字/公式没有凭记忆编写
- [ ] 来源冲突已经标注

## 模板使用
- [ ] 已根据版本选择对应模板（好奇单 → a4-preview-template.html；探索卡 → lesson-card-template.html；速查卡 → quick-check-template.html）
- [ ] 已根据年级/学科/课型选择具体步骤内容
- [ ] 没有无理由重新设计模板
- [ ] 探索卡：六幕齐全（钩子→故事→想一想→联结→上课任务→资源库）
- [ ] 探索卡：背后故事真实可溯源，不低幼化
- [ ] 探索卡：资源真实存在，不编造作品

## 学习质量
- [ ] 有激活旧知或预测
- [ ] 有完整阅读/整体认识
- [ ] 有发现卡点
- [ ] 有初步理解
- [ ] 有自己的猜测
- [ ] 有真实问题
- [ ] 有一次合书检索/表达
- [ ] 有课堂验证连接

## 内容边界
- [ ] 没有直接给标准答案
- [ ] 没有提前讲完教学重点
- [ ] 没有大段复制课文
- [ ] 没有把预习变成第二套作业
- [ ] 探索卡的"背后故事"是播种兴趣，不是提前教知识
- [ ] 探索卡：没有用"拟人化睡前故事"低幼包装
- [ ] 探索卡：没有超纲教学

## 儿童体验
- [ ] 孩子知道每一步要做什么
- [ ] 问题数量不过多
- [ ] 允许答错、允许"不确定"
- [ ] 有一点好奇感
- [ ] 有完成感
- [ ] 预计10~15分钟内可以完成
