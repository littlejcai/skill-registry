# 学习科学原理（为什么这样设计预习）

## 激活旧知

阅读新内容前，先调用孩子已有经验和知识。
- 看标题猜内容
- 看图片猜情境
- 联系生活经验
- 回忆相关知识

目的：让新知识有地方可以连接。

## 元认知监控

帮助孩子判断："我到底懂没懂？"
重点不是假装全懂，而是能够发现：
- 不会的字、不理解的词
- 不明白的句子、不确定的推断
- 觉得奇怪的地方

## 预测与生成

让孩子先猜，再验证。
- 你觉得标题可能在说什么？
- 你猜事情最后会怎么样？
- 你觉得人物为什么这样做？

不要预测之后立即告诉标准答案。

## 主动检索

阅读结束后，尽量让孩子合上书再说一遍。
- 30秒复述
- 一句话概括
- 回忆3个关键词

合书说一遍 > 再读一遍。

## 生成自己的解释

允许孩子猜错、不完整、暂时没有结论。
预习阶段需要的是初始理解，不是标准答案。

## 支架式学习

不同年龄使用不同程度的提示：
- 低年级：谁 → 做了什么 → 结果怎样
- 中年级：人物/对象 → 事情 → 原因 → 结果 → 我的感受
- 高年级：内容 → 证据 → 推断 → 作者意图 → 表达效果
