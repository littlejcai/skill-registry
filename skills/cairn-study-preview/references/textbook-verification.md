# 教材内容核实流程

## 确认教材定位

需要确认：教材版本、科目、年级、学期、第几课/单元。

例如：人教版｜四年级上册｜语文｜第5课

如果用户已经提供课本目录、课题页或教材截图：优先识别已有信息，不重复询问。只有缺少影响教材定位的关键信息时才询问。

## 核实目标

核实：课题、教材定位、必要生字/词语、单元主题、必要背景、课文基本内容。

不要为了生成预习单而把整套教案全部搜出来。核心原则：搜索是为了防止事实错误，而不是为了提前完成课堂教学。

## 搜索策略

优先查询：教材官方/出版社资料 → 权威教育资源 → 教师用书 → 可靠辅助资料。

查询示例：
- `"<版本> <科目> <年级学期> 目录"`
- `"<版本> <年级学期> 第N课 课题"`
- 语文可加：`"<版本> <年级学期> 第N课 生字"`

## 核实规则

- **两个及以上独立可靠来源一致** → 可以采用
- **来源内容雷同**（大量网站复制同一份）→ 只算一个来源
- **来源冲突** → 优先官方/教材来源，不擅自编造，必要时标注"待核实"
- **版本与课次明显不匹配** → 立即STOP，告诉用户存在教材定位矛盾
- **搜不到某个具体信息** → 不要凭模型记忆补充，标【待核实】

## 失败处理

| 触发条件 | 一线处理 | 兜底 |
|---|---|---|
| 搜索结果少 | 换查询词，最多3轮 | 骨架版 |
| 多来源矛盾 | 优先官方/教材来源 | 标注【待核实】 |
| 无搜索能力 | 不编造 | 骨架版 |
| 版本与课次不匹配 | STOP | 请用户确认 |
| 生字/单词来源不一致 | 少列、不猜 | 以课本为准 |
| 课本图片模糊 | 只使用可辨认内容 | 其余【待核实】 |
| 具体课文无法确认 | 不复述 | 通用预习模板 |

## 骨架版

无法可靠确认教材内容时，不能交白卷。输出：
- 教材定位
- 通用预习流程
- 【待核实】字段
- 孩子可以立即完成的问题
- 明确告诉用户哪些内容还未核实
