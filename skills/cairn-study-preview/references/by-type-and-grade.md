# 课文类型与年级规则

## 六步动作链（四科统一骨架）

每科六步均为：看 → 读 → 圈 → 想 → 说 → 问。具体指令：

| 动作 | 语文 | 数学 | 英语 | 科学 |
|---|---|---|---|---|
| ① 看 | 看标题猜故事 | 看课题：今天学什么？你已知道什么 | 看插图/标题猜主题 | 看课题猜要研究什么 |
| ② 读 | 朗读全文 | 读例题：看懂在问什么 | 听读课文并跟读 | 读课文：讲了什么现象 |
| ③ 圈 | 圈生字/不懂的句子 | 圈看不懂的步骤 | 圈生词/不会的句子 | 圈觉得奇怪的地方 |
| ④ 想 | 故事讲了什么？哪个细节最吸引你 | 自己先试做一道，联系旧知识 | 看图猜意，找关键句型 | 猜实验会有什么结果 |
| ⑤ 说 | 合书讲大意 | 合书讲思路 | 合书说大意 | 联系生活：你在哪见过 |
| ⑥ 问 | 最想弄明白的问题 | 哪里还没搞懂 | 不懂的句子 | 最想验证什么 |

下面的「语文课文类型」「其他科目」用于填充第④步"想"的引导问题深度。

## 语文课文类型

### 普通课文
默认流程：读前预测 → 完整阅读 → 找卡点 → 初步理解 → 猜一猜 → 合书复述 → 提问 → 课堂验证

### 写人记事
重点：谁 → 做什么 → 为什么 → 结果 → 我的判断
不要直接告诉"这个人物是一个怎样的人"。让孩子通过细节形成自己的判断。

### 写景/说明
重点：原来知道什么 → 作者写了什么 → 哪个细节特别 → 作者为什么写它 → 我的发现
不要在预习阶段直接把完整写作技法讲透。

### 古诗/古文
重点：读音 → 大意 → 画面 → 不懂 → 我的感受 → 我的问题
除非用户明确要求，否则不把完整译文直接填满预习单。

## 分年级重点

### 一、二年级
重点：读得下来 + 找得到 + 说得出来
优先：看标题、看图、读课文、找生字、找一个有趣地方、说人物/事情、提一个问题
避免：复杂主题、修辞分析、长篇背景

### 三、四年级
重点：发现问题 + 初步解释
加入：上下文猜词义、人物/事情/原因、关键句、情感初猜、为什么

### 五、六年级
重点：证据意识 + 初步推断
加入：哪句话支持你的判断？哪个细节最关键？我的猜测有没有证据？作者为什么这样安排？

## 其他科目

### 数学
预习重点：看课题知道学什么 → 读例题先自己试 → 找看不懂的步骤 → 自己算一道 → 联系旧知识 → 留问题

### 英语
预习重点：读新单词（标音标）→ 听课文录音跟读 → 找不懂的句子 → 看图猜主题 → 合书说大意 → 留问题

### 科学
预习重点：看课题猜研究什么 → 读课文知道什么现象 → 找觉得奇怪的地方 → 预测实验结果 → 联系生活见过什么 → 留观察问题
