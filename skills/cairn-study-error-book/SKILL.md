# 试卷错题整理 (Exam Error Notes)

从试卷/作业图片中识别错题，输出结构化错题本（Markdown）。

## 核心原则

1. **先读全，不猜**：关键字段没读到、读不清、多次读取冲突，都不算读完。
2. **颜色只定位，内容定结论**：翻拍后红笔可能变灰变黑，判定对错以内容（划掉/更正/勾画）为准。
3. **校验驱动（核心提速策略）**：先对每题独立算出正确答案，再对照卷面；**只放大确认"卷面答案≠正确答案"的候选**，正确项不再确认。确认量 ≈ 错题数，而不是"所有模糊字段"。
4. **原图通读保底**：完整题干、跨栏/跨行文本一律以原图 OCR 为准拼装；分区/裁剪只用于字段级确认，不做整页重读，避免把题目拆散。
5. **只列真错题**：无法判断的题目单独说明，不猜测。
6. **并行优先**：所有待确认字段一次批量裁剪完（`--batch`），再一次并行 Read 全部；首次裁剪给足余量、放大到位，避免小图多轮迭代。

## 工作流（校验驱动版）

### 步骤 1：原图通读（L1）

Read 原图，拿到整页上下文：完整题干 + 各题答案草稿 + 布局。列出答案字段清单，标注每处"首读值 / 缺失 / 模糊"。**同时扫描插图并分类**：信息承载于题干文字（几何示意图、月历表等，无需读图）/ 答案依赖图（看图列式、统计图等）/ 装饰（忽略）——见下方"插图处理"。

### 步骤 2：立即校验（先算对错）

对每题独立计算正确答案（校验要点见 `references/answer-checks.md`），与首读值对比：
- 一致 → 排除，不再确认；
- 不一致、首读缺失、或首读本身模糊 → 进入**待确认清单**（错题候选）。

### 步骤 3：批量确认待确认字段（L2，字段级放大）

把待确认清单写进 JSON，一次 `--batch` 裁完，再并行 Read 全部裁剪图。**同栏候选合并成一个"列 box" + `--split`**，Read 次数从每字段 1 张降到每栏 1~2 张：

```bash
cat > /tmp/regions.json <<'EOF'
[
  {"name": "col_fill", "box": [450,850,1520,1430], "zoom": 3, "split": true},
  {"name": "b9", "box": [940,815,1240,945], "zoom": 6, "gray": true, "contrast": 2.0}
]
EOF
python3 <skill_dir>/scripts/crop_zoom.py <image> --batch /tmp/regions.json --outdir /tmp
```

- **坐标免换算**：Read 返回的千分比 box 直接传 `--coords permille`（或 region 里 `"coords": "permille"`），脚本自动换算像素；`ratio` 为 0~1 归一化坐标。
- `--split` 自动分块：输出单边 > 3600px 时按列切成多块（每块 60px 重叠，跨界文字完整），输出 `name_p1.png / name_p2.png…`。
- **插图区独立裁剪**：答案依赖图的插图区作为**独立裁剪项**，整块、不合并、不 `--split`（避免图形被切碎），zoom 3~4 保留图形整体，由视觉描述读取图内信息。
- 坐标按"原图/象限内的相对位置 + 足量边距（±50px 以上）"估位，一次到位；仍偏才修正一次。
- 仍冲突的个别字段以最高倍、最清晰为准，必要时查看画面确认；实在读不出则标记"无法确认"。

### 步骤 4：批改痕迹定位（辅助）

```bash
python3 <skill_dir>/scripts/red_mark_detect.py <image> --out marks.png
python3 <skill_dir>/scripts/red_mark_detect.py <image> --sample x0,y0,x1,y1
```

用于确认"划掉=原答案错；旁侧/下方更正=正确答案；勾=对"。只对存疑区域采样，不做全图遍历。

### 步骤 5：L3 兜底（仅当原图 OCR 整体失败）

原图 OCR 整体不可用（严重歪斜/反光/大面积识别失败）时，才做整页分区：2×2 四象限、**相邻块向外重叠 ≥ 60px**（保证跨界文本至少在某一格里完整），并行 Read 后仍以原图布局拼装题干。

### 步骤 6：模板化输出

按 `assets/error_notes_template.md` 输出错题本：头信息 → 错题一览表 → 每题详解（题目/我的答案/正确答案/错因/解析）→ 复习建议 → 说明（截断、无法判断项）。

**每题详解嵌入卷面证据图（离线优先）**：把该错题 L2 确认时用的裁剪放大图复制到主目录下 `<试卷名>_错题图片/` 子文件夹（命名如 `t1.png`、`sel3.png`），md 用**相对路径**引用（`![](<试卷名>_错题图片/t1.png)`），保证与 md 一起打包后离线可查看，不依赖网络 URL。

### 步骤 7：交付

1. 保存到项目主目录：`<试卷名>_错题整理.md` + 同目录 `<试卷名>_错题图片/`（证据图）。
2. `present_files` 一起交付 md 与图片文件夹。
3. 回复中给出错题一览表与关键结论；文字不重复整篇文档。

## 插图处理（判定决策树，及时止损）

1. **先问：这题判定对错，需要图的什么信息？** 信息能由题干文字 + 数学推理补全（几何示意图、月历/表格、钟表等）→ **不读图**；OCR 对纯图形失败是正常现象，不要反复放大。
2. **答案依赖图**（看图列式/写数、统计图读数据、数轴定位）：把整个插图区作为 L2 独立裁剪项（整块、不 `--split`、zoom 3~4，**首次裁剪给足 ±100px 边距**，宁可大勿切边），以视觉描述读取图内信息。
3. **需要"精确值/精确位置"时，优先数学排除，不追求像素级**：先算出各选项/候选值，用"超出范围、位置偏向"排除（真实案例：选择3 数轴 0~2000 黑点"更靠近1000"，B=2236 超范围必错、C=1550 中点偏 2000 必错），再配合**卷面更正痕迹**（划 C 标 D）定案。**读到"能判定"即停**，定性描述（"更靠近1000"）足够时不再放大，禁止像素级定位（实测 2.5 分钟死磕 vs 数学排除 20 秒）。
4. **插图是查漏关键**：被划掉的选项答案 OCR 可能读成当前值（"划 C 标 D"被读成 (C)），选项类答案必须留意插图/涂改痕迹，可发现 L1 漏掉的错题。
5. **装饰插图**：忽略，不进入任何裁剪清单。
6. 插图可能被分块切碎：涉及插图的区域一律整块裁剪。
7. **禁止现场写未经验证的像素分析脚本**：需要精确读数时用 Read 高倍 + 描述 + 二次确认，不写临时脚本（临时脚本易把刻度线/数字误判为黑点）。

## 局部图快速通道

单边 < 1200px 或明显是试卷局部截图的输入：跳过分区，直接"步骤 1 原图通读 → 步骤 2 校验 → 步骤 3 批量确认"，通常两轮工具往返完成（约 40s~1 分钟）。

## 重复卷识别

若用户上传的图片文件名/内容与历史处理过的试卷一致，直接调用历史结论秒回（并提示"与上次整理结果一致"），无需重跑识别。

## 实测基线

| 试卷规模 | 实测/预期耗时 |
|---|---|
| 局部图（单题区） | ~40 秒~1 分钟（校验驱动，2 轮往返） |
| 完整大试卷（三栏全题型） | ~1 分 30 秒~2 分（原图通读 + 校验驱动 + 批量确认） |

## 详细细则

分层读取、交叉验证、高频误读清单（5↔8、8↔9、二↔四、146↔148、25↔10、35↔45 等）见 `references/workflow.md`。多科目（语文/英语等）同流程，答案校验改为对应学科规范。
