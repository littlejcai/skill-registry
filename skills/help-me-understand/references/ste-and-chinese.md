# STE 原则与中文适配

这里区分官方规则摘要、中文适配和本技能新增的方法。规则定位以 ASD-STE100 Issue 9 为准，见 [来源说明](sources.md)。这是选择性转述，不是标准译本或完整规则表。

## A. 官方规则中与本技能直接相关的部分

| 规则定位 | 要点 |
| --- | --- |
| 1.1、1.11 | 通用词汇之外允许专业术语；同一对象的专业名称保持一致 |
| 3.6 | 使用主动语态；说明文字中行动者未知时允许被动语态 |
| 4.2、4.4 | 不靠省略必要词语缩短句子；相关句子要有连接 |
| 5.1—5.4 | 操作句最多 20 个英文词；通常一句一项指令，同时动作有例外；先交代必要条件 |
| 5.5 | 注释不承担必须执行的指令、要求或限值 |
| 6.1—6.6 | 说明逐步展开；一句最多 25 个英文词；一段一个主题，最多六句 |
| 9.1 | 逐词替换不够时，重新组织句子 |

英文词数还受第 8 节的计数规则约束，不能按空格数量直接判断正式合规。原文中有关词性、批准词义、动词形式的要求，需查官方词典。日常使用的简单英语不自动等于正式 STE。

## B. 中文适配：保留目标，不机械换算

以下是本技能的中文设计，不是官方中文 STE 规范。

1. **稳定名称，解释术语。** 首次出现用“术语＋简短含义”，后文保持一致。必要专业概念不要统统改成“工具”“系统”。名称相似也不代表对象相同。
2. **讲清动作与关系。** 优先用明确主语和动词。原文没有给出主语、原因或执行者时保留未知，不用常识填空。
3. **一句围绕一件事。** 长句确实妨碍理解时才拆；保留并发、比较、否定和从属关系。不把 20/25 个英文词换成中文字符上限。
4. **先交代行动前提。** 条件影响能否执行时，把它放在动作前；若条件本身不明，先指出缺口。
5. **分段也保留连接。** “因为”“所以”“如果”“同时”表达真实关系时保留。把隐含关系讲出来，不靠删连接词制造简洁感。
6. **区分说明与操作。** 解释原理逐步建立背景；给操作步骤时明确顺序、分支和完成条件。段落长度以能读懂为准，不把六句当中文合格线。
7. **准确性优先于形式。** 保留概率、范围和证据强度；更长的准确句优先于更短的错误句。口语化不能把“有条件的建议”变成“无条件的要求”。

不从英文规则推导中文禁词表，不全面禁用被动句、分号、比喻、术语或重复。也不保证达到某个“STE 百分比”。

## C. 本技能新增的理解设计

这些方法服务于个人学习，不声称由 ASD-STE100 提出：

- 识别理解障碍，再选择文字、图示或交互网页。
- 把机制、证据和边界讲全；材料没有提供的证据明确标缺口。
- 类比保留结构对应，说明它在哪一步会失效。
- 图示明确箭头语义；交互明确依据和教学假设。
- 读者说没懂时改变解释路径，不循环输出同一段话。
- 用能否复述关键关系、辨别条件和例外评价解释；不把句子短、字数少或风格检查分数当成理解证明。

## 自拟反例：看似更顺，实际变了意思

| 材料说法 | 错误简化 | 正确处理方向 |
| --- | --- | --- |
| 传输期间文件损坏，原因未知 | 传输程序损坏了文件 | 保留损坏事实与原因未知 |
| 只在内部报告中观察到变化 | 各种资料都有效 | 保留测试材料范围 |
| 可能缩短阅读时间 | 能缩短阅读时间 | 保留“可能”，不升级确定性 |
| 同时检查格式与权限 | 先检查格式，再检查权限 | 明确两项同时进行 |
| 两项都通过才进入处理 | 通过一项就继续 | 保留“全部满足”的条件 |
| 试验观察到 A 与 B 同时变化 | A 导致 B | 保留观察关系；原因需另有证据 |

若无法在保留原意的前提下让一句话更顺，保留必要精度，并只说明具体难点。
