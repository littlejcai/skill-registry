# 分享卡片设计规范

用户要求"做成图片/卡片/分享"时，按这个规范生成竖版 HTML 卡片。模板在 `assets/review-card-template.html`，复制后填数据即可。

## 设计原则

- **每次只换内容，不换设计**：配色、圆角、间距、字体、模块顺序都固定，不要自由发挥。
- **手机截图友好**：最大宽 420px，竖版，一屏多一点，截图就能发。
- **飞书版和整图版同源**：模块顺序、错误/正确的视觉关系、配色，两边一致。

## 配色

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| 页面背景 | `#f5f1ea` | 米色底 |
| 卡片背景 | `#ffffff` | 白色卡片 |
| 主色 | `#2e7d5b` | 墨绿：标签、标题高亮、进度条、正确说法、编号 |
| 错误色 | `#b8543a` | 砖红：错误说法、删除线 |
| 正文 | `#2d2d2d` | 深灰 |
| 辅助文字 | `#888888` | 灰色小注 |
| 四类问题辅色 | `#2e7d5b` / `#5a9e8f` / `#d4a94a` / `#e8915a` | 进度条四条：墨绿/青绿/金/橙 |

## 模块顺序（固定）

1. **顶部**：小标签（如"AI 英语复盘"）+ 主标题（两行，数字高亮主色）+ 副标题
2. **问题分布**：四行，每行 类型名 + 进度条 + 数量
3. **错误对照**：卡片列表，每条 错误说法（删除线砖红）→ 正确说法（深色加粗）→ 小注（灰色）
4. **高频搭配**：双栏网格，每格 误用（删除线）→ 正确（主色加粗）
5. **三条建议**：圆形编号 + 一句话
6. **结尾**：居中金句（主色加粗）+ 小字副标题

## 视觉细节

- 卡片圆角 20px，内块圆角 10-12px
- 卡片阴影：`0 8px 32px rgba(0,0,0,0.06)`
- 字体：系统无衬线（-apple-system, PingFang SC, Microsoft YaHei）
- 模块间距：标题区和第一个模块之间留白最大，模块之间 28px
- 错误对照每条：浅米色底 `#faf8f4`，圆角 12px

## 数据填写规则

- **错误对照**：挑 6-8 句最有代表性的，不要全放。流利度问题（重复口误、犹豫词）不进对照列表。
- **高频搭配**：挑 8 个，双栏网格刚好填满。
- **建议**：固定 3 条，编号 1/2/3。
- **金句**：结尾固定用"练 20 分钟，复盘 10 分钟——比盲目多聊一个月有用"这一类，根据本次练习时长微调。
- **隐私**：如果用户没说"脱敏后发布"，不主动删工作细节；用户说要分享时，把职业细节泛化（OA 系统 → the tool / the system）。
