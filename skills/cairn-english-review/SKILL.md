# 英语口语练习复盘

把一段口语练习对话变成一份可复习、可对照的学习文档。

## 整体流程

三步主流程 + 一个可选步骤：**提取对话 → 分析问题 → 生成复盘文档 →（可选）生成分享卡片**。

### 第一步：提取对话

输入可能是三种形式，按实际情况处理：

1. **豆包会话链接**（`doubao.com/thread/xxx`）：
   - 直接 HTTP fetch 会被 robots 拦截，必须用浏览器打开。
   - 使用 `browser-use-automation` skill（`computer_use_tool`，`plane="bu"`）：`bu.navigate` 打开链接 → `bu.get_page_text` 提取全文 → 必要时 `bu.screenshot` 辅助确认。
   - 把提取到的对话先存一份本地备份（工作目录下 `english_practice_raw.md`），后续分析都基于这份本地文本，避免重复打开浏览器。
2. **用户直接粘贴的聊天记录/转录文本**：直接用，跳过浏览器步骤。
3. **音频/视频转录**：提示用户先用语音转文字，再把文本发来。

提取后确认：发言轮次完整、用户（"我"）的英文发言和 AI 的回复都在。缺用户发言的轮次无法做错误分析，要先补齐。

### 第二步：分析问题

按四类错误框架逐句分析用户的每一句英文发言。分类法和常见示例见 [references/error-taxonomy.md](references/error-taxonomy.md)。

分析时同时产出：
- **逐句对照**：每一句用户发言 → 错在哪（标注类型）→ 正确说法。
- **"想说的话"对照**：用户没说清楚、卡壳、或者用中文想表达但没组织好的，补成一句干净的英文。
- **词汇清单**：这次对话里值得记住的词、词组、搭配，按出现顺序列。
- **问题分布**：统计四类错误各有多少处，挑最突出的 2-3 类作为改进重点。

### 第三步：生成复盘文档（默认）

用 `lark-doc` skill 创建一份飞书文档，结构按 [references/review-template.md](references/review-template.md)。排版要有卡片节奏感，不是纯表格堆砌：
1. 开头 callout：一句话总结主要问题 + 四类错误数字。
2. 对话还原表（轮次 | 用户说 | AI 回复）。
3. 问题分布：callout 块突出四类数字和一句总结。
4. 逐句对照：表格三列（错误说法 / 正确说法 / 小注），错误句用红色或删除线标注。
5. "想说的话"对照表。
6. 高频搭配：双列表格，错误→正确。
7. 改进建议：编号清单，3 条以内。

交付前回读文档，确认表格、对照、词汇清单都渲染正常。

### 第四步：生成分享卡片（可选）

当用户说"做成图片/卡片/发朋友圈/小红书/整图"时才触发。
按 [references/card-design-guide.md](references/card-design-guide.md) 的规范，复制 [assets/review-card-template.html](assets/review-card-template.html)，把本次复盘数据填进去，生成一张竖版 HTML 卡片。
配色、模块顺序、圆角间距都按模板走，每次只换内容不换设计。
生成后用 `present_files` 交付 HTML 文件。

## 关键注意事项

- **保留用户原话**：这是用户的个人学习文档，不是公开文章，不要"脱敏"用户说过的英文原句。如果用户后续要把复盘发出去，再单独提示隐私处理。
- **错误判断要克制**：不确定的语法点标"建议确认"，不要硬判错。中式直译和地道表达之间是程度问题，写"更自然的说法"而不是"你错了"。
- **一次复盘聚焦**：问题分布统计后，改进建议只挑最突出的 2-3 类，不要列十条八条。
- **依赖 skill**：对话提取依赖 `browser-use-automation`，文档生成依赖 `lark-doc`。调用前按对应 skill 的要求读取其 SKILL.md。
